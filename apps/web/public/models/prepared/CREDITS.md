# Prepared demo models (VS-T52)

Made for this project in Blender (bpy) by code, from the 360° tour photos (`public/tour/`, CC0, Poly Haven):
`video/blender/{sofa,car,house}.py`, rebuilt with `make prepared-models`. Same licence as the repository.

| Folder              | Object of the tour photo                                   |
| ------------------- | ---------------------------------------------------------- |
| `hall-sofa/`        | Baroque tufted sofa (`studio/hall.jpg`, Marry Hall)        |
| `street-car-white/` | White estate car (`outdoor/street.jpg`, Stuttgart Suburbs) |
| `terrace-house/`    | Cottage with blue French doors (`outdoor/terrace.jpg`)     |

They are the **offline mock's** answers for these three objects: with the Meta models on, the views and the 3D come
from the live pipeline.
